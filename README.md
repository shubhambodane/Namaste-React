- Faster Builds because of caching
- Image optimization
- Minification of files
- Bundling of files
- Compress files
- Consisting Hashing
- Code Splitting
- Differential Bundling - support older browsers
- Diagnostic
- Error Handling
- Https hosting
- Tree Shaking - remove unused code
- Different dev and prod bundles
